# ANTI_PATTERNS.md

## Avoidance Contracts

These patterns are disallowed by default unless explicitly overridden by project context.

- Corporate language
- Motivational clichés
- Overexplaining
- Academic inflation
- LinkedIn tone
- Safe conclusions
- Unmotivated certainty
- False urgency

## Anti-pattern governance

- Every pattern here has a severity tag:
  - `high`: never allow
  - `medium`: require explicit owner override
  - `low`: allow only with context rationale

## Placeholder matrix

| Pattern | Default severity | Allowed override route | Notes |
|--------|------------------|-----------------------|-------|
| Corporate language | high | no | Preserve directness |
| Motivational clichés | high | no | Avoid template writing |
| Overexplaining | medium | task-specific | Use sparingly |
| Academic inflation | medium | reviewer-approved | Preserve readability |
| LinkedIn tone | high | no | Reserve for non-author channels only |
| Safe conclusions | high | no | Require explicit uncertainty |
