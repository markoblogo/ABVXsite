# Language Tools, Protocols & Experiments for Toki Pona

Language tools make a language usable across more than one format. In the ABVX catalogue, the work spans AI-assisted translation, sitelen pona display, visual communication and experiments with emoji-based representation. These projects treat language as a system of choices and conventions, not only a list of translated words.

The [Toki Pona Toolkit](/work/toki-pona-ai-translator) brings together translation, sitelen pona and emoji rendering work with reusable packages and manuscript quality checks. The [sitelen-layer-plugin](/work/sitelen-layer-plugin) supports switching Toki Pona content among Latin script, sitelen pona and emoji modes. [Pictiq](/work/pictiq) explores a minimal visual protocol built from icon tiles and composition rules, while [sitelen-emoji](/work/sitelen-emoji-truth) records an evolving Toki Pona-to-emoji mapping and helper library.

## Translation is reconstruction

A sentence from a language with a large vocabulary may need to be reorganized before it can be expressed in a deliberately small language. Meaning depends on context and relationships among ideas; a literal dictionary substitution can lose the point. Translation tools can help draft or render alternatives, but choices still need review against the intended meaning and the conventions of the project.

## Protocols support consistency

Visual languages and writing systems need decisions about vocabulary, composition and ambiguity. A protocol records enough of those choices for books, websites and software to use them consistently. It does not declare one approach universally correct, and it can evolve when a change is documented.

This distinction matters in experimental work: a prototype can show a possible approach without claiming a settled standard. Explore the individual project pages to see the scope of each tool, protocol and language experiment.
