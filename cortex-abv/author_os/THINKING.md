# THINKING.md

## Thinking System Template

### Problem framing

- State the real problem before selecting a method.
- Enumerate what is known, uncertain, and assumed.
- Separate user goal from system goal.

### Systems thinking

- Detect feedback loops.
- Identify boundary conditions.
- Track second-order effects.
- Explicitly mark dependencies across projects/channels.

### First principles

- Reduce to definitions, constraints, and invariants.
- Reject inherited assumptions without evidence.
- Rebuild conclusion from primitive premises.

### Paradox handling

- Identify contradictory claims.
- Preserve both sides when both are valid.
- Resolve through explicit trade-off rule.

### Incentives

- Distinguish stated vs hidden incentives.
- Identify stakeholder-level and system-level effects.
- Mark incentive-aligned or misaligned signals.

### Trade-offs

- Define measurable criteria.
- State what is sacrificed and what is protected.
- Keep one explicit non-negotiable constraint per decision.
