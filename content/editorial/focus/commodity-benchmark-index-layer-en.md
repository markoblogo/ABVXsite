# **Benchmark and Index Layer for Physical Commodities**

A benchmark is useful only when its reference is defined clearly enough to interpret. Participants need to know which commodity, location, delivery basis, observation window and methodology an index represents, as well as what information is excluded. SPIKE and UGA Index are examples of public Ukrainian spot-reference work described in this ecosystem.

An index is not automatically an offer, an executable price or a guarantee of market-wide representativeness. Its role is to make a stated reference easier to inspect and compare over time. Publishing methodology and dated observations helps analysts, exporters, processors and traders judge whether the reference is relevant to their own decision.
