# WRITING.md

## Writing Principles (template)

This document describes how content should be structured before domain/project specialization.

## Core principles

- Clarify first, then stylize.
- Keep argument spine visible.
- Define claims before examples.
- Prefer reversibility over absolutes.
- Use evidence markers for non-obvious assertions.
