Framewright is an evolving collection of video-production methods, recipes and agent skills. It helps choose a workflow for a specific task, combine tools when needed and keep evidence of what actually worked.

## Start with the task

The catalogue covers short software launches, book and product trailers, brief announcements, cinematic movement around existing React interfaces and authored motion graphics.

Each route records its tested scope and limits. The collection includes work with Brag, Hyperframes, Flute, Remotion, local Kokoro narration and FFmpeg finishing. A renderer can be paired with a small companion tool for music, thumbnails or another missing deliverable.

## Keep the evidence

Completed examples include the AMI and AsciiTheme launch videos, French and English book trailers, the CoqPi interface film and Framewright's own identity film. A successful export supports that particular workflow; it does not establish audience engagement or conversion gains.

Failed experiments stay visible too. A combined visual-and-sound prototype that did not pass quality checks remains a recorded limit, rather than a promoted capability.

## Current stage

Framewright is experimental. Its router is structurally validated, but the scenario suite has not yet been evaluated by an independent model. It recommends production workflows; it does not install upstream tools, render films or publish autonomously.

The repository contains original routing instructions, recipes and technical evidence. Upstream software, skills and media retain their own licences.
