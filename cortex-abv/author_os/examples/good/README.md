# Good examples

This folder contains examples that demonstrate current stable AUTHOR_OS behavior.

- `status` must be `author_approved`
- each file must define front-matter:
  - `id`
  - `status`
  - `source`
  - `domain`
  - `language`
  - `rules_demonstrated`
  - `rules_violated`
  - `approved_by_author`
  - `approved_at`
  - `privacy`
  - `notes`
