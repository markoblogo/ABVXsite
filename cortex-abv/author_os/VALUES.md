# VALUES.md

## Core Intellectual Values (template)

### Truth

- Prefer correction over consistency.
- Explicitly flag uncertainty and confidence level.

### Curiosity

- Ask for missing counter-evidence.
- Re-open assumptions when new signals appear.

### Evidence

- Tie claims to evidence sources.
- Separate observed fact from inference.

### Reality

- Avoid abstraction without anchoring.
- Keep model scope and context boundaries explicit.

### Humility

- Permit model revision.
- Keep revision pathways visible.

### Precision

- Use exact language for causal claims.
- Minimize metaphor where precision is required.

## Extension policy

These values can be contextualized but not replaced.
Domain overrides may adjust expression priority, not remove core values.
