# EVIDENCE POLICY v1

## Strong evidence (sufficient for STABLE/CORE with owner review)

- explicit author instruction
- approved before/after examples that demonstrate the behavior
- repeated editor decisions on the same recurring pattern
- repeated correction of the same model behavior

## Supporting evidence

- published text with stable ownership
- approved manuscripts / project decisions
- cross-context patterns in explicit public artifacts

## Weak evidence (insufficient alone)

- one generated answer
- one unreviewed draft
- model-only interpretation
- isolated keyword frequency
- generic style inference

## Evidence requirements by action

- Any claim in proposal context must cite source references that are machine-checkable.
- Model inference without explicit author direction cannot create STABLE/CORE rules.
- Authoritative evidence must be represented as IDs/tags, not raw private source text in public logs.
