# Software Override Template

## Scope

This override applies to software architecture, technical reviews, engineering docs, and product planning text.

## Extends

- `THINKING`
- `WRITING`
- `ANTI_PATTERNS`

## Replaces

PLACEHOLDER: `NONE` (default)

## Rule additions

- `risk`: placeholders for implementation and rollout risk levels
- `verification`: placeholders for evidence requirements
- `precision`: technical definition policy

## Governance

- Prefer reproducible steps over ambiguous claims.
- Explicitly separate assumptions, constraints, and known unknowns.
