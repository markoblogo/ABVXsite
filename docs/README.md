Public content already managed in the runtime store must not be edited through its older bundled file. Scheduled publication pools keep their separately authorized route. Private drafts, cover reserves, owner approvals, operator credentials, backup archives and observation journals stay outside Git. A document describing a feature, credential or schedule does not authorize creating or activating it.
