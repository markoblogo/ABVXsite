Pictiq site is the public reading surface for the Pictiq project: a minimal visual protocol for short messages across language barriers. It presents icon tiles, the Core vocabulary and the first free handbook without claiming to replace natural language or long-form writing.

The site makes the protocol easier to inspect and use in context, while the linked GitHub project retains the canonical specifications, lexicon, layouts, validation tools and active development record.
