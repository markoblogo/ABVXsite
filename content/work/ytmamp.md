YTMamp is a lightweight media remote inspired by the operational simplicity and visual identity of Winamp.

The project combines:
- a macOS app,
- a Chromium companion,
- YouTube Music integration,
- retro-inspired interaction patterns,
- and a token-protected local integration API.

It remains independently installable. Its local API is the planned integration seam for Pocket OS playback controls and status display.
