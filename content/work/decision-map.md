Decision Map is an installable Agent Skill and open protocol for decisions with interacting assumptions, risks, dependencies, and downstream effects.

It helps an agent and operator:
- frame the decision and evidence boundary,
- compare explicit options,
- expose assumptions and contradictions,
- record a chosen path and its consequences,
- and revisit the decision through a cascade log.

The standalone repository remains the protocol and release home; ABVX Agent Skills carries the skill in the wider reusable workflow catalogue.
